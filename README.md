# Computational Theory Assessment

This repository contains my assessment for the Computational Theory module.

## Contents
- `problems.ipynb`: the notebook with all problems, explanations, code and tests
- `requirements.txt`: the approved Python packages

## Setup
```bash
git clone https://github.com/obnwachukwu/computational-theory.git
cd computational-theory
python -m venv .venv
.venv\Scripts\activate        # Windows (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt


## Usage
Open `problems.ipynb` in VS Code or JupyterLab, select the `.venv` kernel, and click **Run All**.
